# Quick Installation Guide

## Load Extension in Chrome (5 Simple Steps)

### Step 1: Open Chrome Extensions
- Open Chrome and navigate to: `chrome://extensions/`
- Or: Menu (⋮) → More Tools → Extensions

### Step 2: Enable Developer Mode
- Find the toggle switch labeled "Developer mode" in the top-right corner
- Turn it **ON**

### Step 3: Load Unpacked Extension
- Click the "**Load unpacked**" button (appears after enabling Developer Mode)
- A file browser will open

### Step 4: Select the Spark Folder
- Navigate to where you downloaded/cloned the Spark folder
- Select the **Spark** folder (the one containing manifest.json)
- Click "Select Folder" or "Open"

### Step 5: Test It!
- Open a new tab in Chrome (Ctrl+T / Cmd+T)
- You should see your new Spark tab page! 🎉

## Verification

If successfully loaded, you should see:
- ✅ "Spark - New Tab" in your extensions list
- ✅ A new beautiful tab page when you open new tabs
- ✅ Current time and date displayed
- ✅ A daily inspirational quote

## Troubleshooting

### "Cannot load extension" error
- Make sure you selected the correct folder (contains manifest.json)
- Check that all files are present: manifest.json, newtab.html, styles.css, script.js

### Icons showing as default/blank
- This is normal! Icons are optional
- The extension will work perfectly without custom icons
- See `icons/HOW_TO_CREATE_ICONS.md` if you want to add custom icons

### New tab page doesn't change
- Click the refresh icon (🔄) on the Spark extension card in chrome://extensions/
- Close ALL tabs and open a new one
- Restart Chrome if needed

## What's Next?

Once loaded, you can:
1. Set your main focus for the day
2. Add tasks to your todo list
3. Change the background image in settings (⚙️)
4. Enjoy your productive new tab!

## Uninstalling

To remove the extension:
1. Go to `chrome://extensions/`
2. Find "Spark - New Tab"
3. Click "Remove"
4. Confirm removal

Your new tab will return to Chrome's default page.
