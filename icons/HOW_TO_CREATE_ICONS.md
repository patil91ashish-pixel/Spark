# How to Create Icons

The extension needs three icon sizes for Chrome:

- **icon16.png** - 16x16 pixels (shown in the extensions bar)
- **icon48.png** - 48x48 pixels (shown in the extensions management page)
- **icon128.png** - 128x128 pixels (shown in the Chrome Web Store)

## Quick Method: Use an Online Generator

1. Go to https://www.favicon-generator.org/
2. Upload a square image (at least 128x128px)
3. Download the generated icons
4. Rename them to icon16.png, icon48.png, and icon128.png
5. Place them in this `icons/` folder

## Design Suggestions

For the Spark extension, consider:
- A spark/lightning bolt symbol ⚡
- A sunrise/sunset icon 🌅
- A minimal star/sparkle ✨
- Simple geometric shape in gradient colors

## Quick Fix: Download Pre-made Icons

You can also search for free icons on:
- https://www.flaticon.com
- https://icons8.com
- https://www.iconfinder.com

## Temporary Solution

The extension will work without icons, Chrome will just show a default placeholder icon.
